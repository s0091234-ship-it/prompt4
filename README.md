# 바로바로 프롬프트 (Prompt-Copy)

> 구글 스프레드시트와 실시간 연동되어 원하는 프롬프트를 즉시 검색하고 원클릭으로 복사할 수 있는 반응형 원페이지 웹 애플리케이션입니다.

---

## 📌 주요 특징
1. **로그인 불필요 (Zero Friction)**
   - 별도의 로그인이나 가입 없이 웹페이지 접속 즉시 100% 무료로 바로 이용 가능합니다.
2. **원클릭 클립보드 복사**
   - 원하는 프롬프트의 **[복사하기]** 버튼 클릭 시 클립보드에 즉시 복사되며, 시각적 체크 애니메이션 및 토스트 알림이 뜹니다.
3. **실시간 검색 & 키워드 하이라이팅**
   - 프롬프트 이름과 본문 내용 전체를 실시간으로 검색하며, 검색된 키워드를 즉시 형광펜처럼 하이라이팅 표시합니다.
4. **구글 스프레드시트 실시간 동기화**
   - 구글 스프레드시트의 최신 데이터를 자동으로 동기화하며, 상단 새로고침(🔄) 버튼을 통해 언제든 즉시 갱신할 수 있습니다.
   - 오프라인 환경이나 네트워크 차단 시에도 내장된 36개의 프롬프트 데이터로 즉시 로딩을 보장합니다.
5. **한국 사용자 최적화 가독성 (Pretendard 볼드체)**
   - 한국 실무 1위 서체인 **Pretendard**를 적용하고, 얇은 폰트를 배제하고 **SemiBold(600), Bold(700), ExtraBold(800)** 굵기를 채택하여 어떤 화면에서도 또렷하고 선명하게 보입니다.
6. **스마트 페이지네이션 (Pagination)**
   - 대량의 프롬프트도 쾌적하게 탐색할 수 있도록 10/20/30/50개 단위 페이징과 스마트 번호 축약 네비게이션을 제공합니다.
   - 검색, 태그 필터, 뷰 모드 전환 및 부드러운 스크롤 이동과 완벽히 연동됩니다.
7. **테이블 뷰 & 카드 그리드 뷰 & 다크/라이트 모드 지원**
   - 사용자 취향에 따라 스프레드시트 형태의 **테이블 뷰** 또는 직관적인 **카드 그리드 뷰**로 자유롭게 전환할 수 있습니다.
   - 눈의 피로를 줄여주는 **다크 모드**와 깔끔한 **라이트 모드**를 지원합니다.

---

## 🚀 실행 방법

### 방법 1: Node.js 로컬 서버 실행 (권장)
```bash
node server.js
```
웹 브라우저에서 `http://localhost:5500`으로 접속합니다.

### 방법 2: 웹 브라우저에서 바로 열기
- 폴더 내 `index.html` 파일을 더블 클릭하여 크롬, 엣지, 웨일 등 원하는 브라우저에서 바로 열 수 있습니다.
